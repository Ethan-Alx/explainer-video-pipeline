# 通用制作策略：explainer_v72

这是明确选择的可调筛查策略，不是频道品牌或自动审美评分。当前用户的画幅、受众、语速、字幕和预算决定实际制作。

启用`preset_id: explainer_v72`，`channel_id`填本人标识。见[策略示例](../assets/production_policy.example.json)。无策略旧计划不强迫改写；未选择此preset的频道不自动启用。相对证据/账本以project_identity.project_root为基准；缺身份旧计划以计划所在目录为基准。

- 普通静帧建议≤8秒；8–10秒复查；>10秒注明可核理由。解释长镜必须有实际分阶段状态、对象/关系/结果推进；不能分割同图绕开长镜审核。
- 运镜连续预览中明显。默认筛查相对缩放差≥0.20或画布平移≥0.08；近景保护、阅读停稳、局部主动作可注明例外。数字达标不证明实播明显；X/Y节点配对并原生验证。
- Flow视频建议≤5段、总付费提交≤5，失败/重试跨run计入。用户可明确调整预算；未知结果查询原任务。无重大错误不为小瑕疵反复生，素材绑定真实任务。
- 1080p标签默认最小40px、声明对比≥4.5；实际观看复核。复杂背景加实际渲染的局部底片并绑定图层，不能只写一个backing字段。放不下按状态分开，仍不可读省略字并高亮对象。
- 所有检查区分数值、文件证据、离线预览和目标机实播。缺试听/实播留pending，不补写通过。

命令：`python scripts/production_policy.py audit --plan <本片计划> --stage planning --report <报告>`；完成态使用`--stage final`。JSON契约与脚本帮助以当前实际CLI为准。
