# 质量门与检查边界

每项记pending/passed/failed/not_applicable、方法、时间、检查者与相对证据路径；JSON只证明结构，不证明美感。

| 阶段 | 核实 | 不足以代替的证据 |
|---|---|---|
| 输入/频道 | 原文件SHA、语义一致、自己的身份画风及授权 | 旧聊天或别人的配置 |
| 分镜 | cue无漏重、说明目的、事实有据、变化有收益 | 固定镜数或等长切片 |
| 生成 | 真实任务ID、参考/提示SHA、资产绑定 | HTTP成功、仅排队、命名 |
| 实图 | 角色、对象、比例、alpha与构图 | 尺寸或哈希 |
| 组合 | 相机+主图+贴片+字+可选字幕的全过程 | 孤立白底图或静态布局卡 |
| 连续代理 | 先后、阅读、声音落点、转场边界 | 写入关键帧的数量 |
| 原生结构 | 轨道、素材、时长、X/Y、字体、注册坐标 | 离线预览顺滑 |
| 目标机 | 当前编辑器实播、试听、短导出 | 本包测试通过或旧机器证据 |
| 导入 | 实际目录、索引唯一条目、引用存在 | 只有导入脚本或MP4 |

选择覆盖角色操作、特写、结构、比较、逐步过程和字密场景的代表样本。数量随风险，不固定。反馈可能对应共用模板缺陷：检查全部受影响镜，再修模板和相关资产，不只修点名镜。

长镜需实际新增信息，不以推拉或闪字充当说明。字体/标签在复杂背景、运动和缩小状态复核；关键物件不被遮住。科学关系和视觉隐喻分别审。声音许可与试听分别记录。新机器先短样稿，不把静态基准顺滑当作动态修复。

交付写草稿名称、输入SHA、真实素材、替换/复用范围、结构/代理/目标机三类检查、未完成项和实际耗时。已导入但尚未试听可这样直说。公开包的技术示例没有用户美术验收，不应伪造批准字段。
