# 生图渠道与资产登记

本技能管理创作和队列，不携带浏览器登录，也不假定固定工具名称或私有网页端点。查看当前工具清单，使用本机可用的浏览器工具和真实页面控件。用户先前对自己账户的授权可延续到其已明确范围；分享给另一个人不会转移授权。

## 渠道选择

- **Flow 官方网页**：用户选择并已具备登录与额度时作为主渠道，实际确认当前模型、比例、张数与参考图。网页模型名称和参考限制会变；不能把历史 Nano Banana 2.1、16:9、单张等记录写成永远支持的 API 参数。
- **GPT 官方网页**：按用户的选择制作复杂细节、标注示意等；精确文字仍优先作为后期可编辑层。使用当前网站真实能力，不声称不存在的直连接口。
- **API 补充**：用户已选定提供商并授权本次用量时可用于次要场景等。核对本人所选提供商当前文档、模型和分组，不迁移他人凭据或消费授权。

Flow 并发依据本次页面真实能力和用户允许的数量；历史 8 并发不是通用默认。网站访问被连接器阻止时应报告实际拦截层，不把聊天授权当作访问已解除，不反复无效提交。

## 任务记录最小内容

每项真实任务记录：镜号/对象、完整提示文本及 SHA、参考文件及 SHA/身份或风格用途、渠道和实际模型、提交起止、实际任务/资产 ID、结果状态、下载相对路径和 SHA。提示重写、参考偏差与失败尝试要有记录；图片与镜号的绑定依据任务关联。

规划、提交、下载、审阅、绑定是不同事实；页面提交成功不代表图片已下载、下载完成不代表视觉通过。本包绑定器的队列状态保持 `downloaded`，审阅写入独立 `visual_review`，绑定写入活动计划记录，具体字段见 [作者与任务格式](storyboard-format.md)。等待或结果未知时先查询原任务，不能无条件再提交。保存实际计时，批量墙钟时间按首次开始至最后完成计算，不简单相加每张并发耗时。

## 后续分镜一致性

含 IP 的镜头绑定已选身份参考；风格参考与身份参考分开。原身份图和头像不是可互换的全身姿态参考。必要时建立该角色的动作/表情资产，检查头身比例、五官、手套等少数识别锚点，不借复杂配饰维持身份。成图漂移仍要实际查看。

图片迭代保留来源，采用清单指向最终文件；不把尚未采用或已拒绝图片自动加回后续参考。动态解释可生成一张结构准确的母图与若干真实状态/前景对象，再切分成可编辑层。若几何地图/线路有准确数据来源，可使用矢量或代码原生图形；不要把简单几何替代用户需要的主体完成插画。

## 当前并行与视频预算

显式选用此策略的频道按[制作策略](production-v72.md)每片最多5段Flow视频/5次付费提交，失败和重试登记，未知结果先查询。图片任务预算另按本期范围。多片按[并行隔离](parallel-production.md)绑定本片实例、run、Flow项目/标签及task_id；下载不能按最新文件猜。独立页面不代表账户额度隔离，共享界面操作排队。
